# 3rd Human

Website for **3rd Human**, a dream for a new world where people know themselves, think for themselves, speak with kindness and live for each other. Created by Jitin Khanna.

Live domain: **3rdhuman.co.in**

## Deploy on Vercel

This is a plain static site: no build step, no framework.

1. In Vercel, click **Add New → Project** and import this repo.
2. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
3. Click **Deploy**.

Every push to `main` redeploys the site automatically.

## Making changes

- Change words: edit the matching `.html` file and commit.
- Change colours or fonts everywhere: edit `style.css` (the tokens at the top).
- Add an image: put it in `img/` and reference it as `img/your-file.jpg`.
